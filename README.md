# ⚡ Electric Circuits Lab Simulator

Welcome to the **Electric Circuits Lab**, a next-generation, interactive web-based electronics simulator developed by the students of SRMIST. This project takes a classic, powerful circuit simulation engine and wraps it in a modern, premium, glassmorphic UI designed specifically for engineering students.

## 🌟 Key Features

- **Real-Time Simulation**: Build and simulate complex analog and digital circuits directly in your browser.
- **Modern User Interface**: A completely redesigned, intuitive dark-mode interface featuring a glassmorphic aesthetic.
- **Custom Tab System**: Easily navigate between the Simulator, Introduction, Step-by-Step Procedures, Developer Credits, and Feedback forms without ever losing your circuit progress.
- **Advanced Oscilloscope**: Expanded and customized oscilloscope views with support for engineering units (µA, mA, kV, etc.).
- **Zero Installation**: Entirely web-based. Runs flawlessly on any modern browser.

## 📝 Usage

To run this project locally on your machine:
1. Clone the repository: `git clone https://github.com/SiD4422/Electric-Circuits-Lab.git`
2. Open the folder and run a local web server (e.g., using Python: `python -m http.server 8080`).
3. Open your browser and navigate to `http://localhost:8080`.
